# Промышленная антифрод-система детекции P2P-переводов

Высокотехнологичное сквозное ML-решение для предотвращения финансового мошенничества при совершении P2P-переводов на основе исторического и сессионного платежного поведения клиентов. Проект реализован с использованием стека Python (Pandas, CatBoost, Scikit-Learn) без использования сторонних СУБД.

## Ключевой стек технологий и методы

### 1. Data Engineering & Предобработка (Чистый Pandas)
* **Аппаратная защита от заглядывания в будущее**: Интеграция P2P-переводов с историей покупок реализована через асимметричный хронологический джойн `pd.merge_asof(direction='backward')` с жестким ограничением истории в 7 дней (`tolerance`).
* **Динамические сессионные маркеры**: Полный отказ от дрейфующих кумулятивных счетчиков. Внедрены расчеты интервалов времени между транзакциями в секундах (`time_diff`) и оконные вычисления локальных шоков сумм (`rolling.mean`). Усечение выбросов (Clipping) выполнено по 99-му перцентилю.

### 2. Машинное обучение и Блендинг
* **Байесовское сглаживание Target Encoding**: Вычисление репутационных показателей получателей (`RecipientID`) и отправителей (`UserID`) со штрафованием коротких сессий. Это полностью решило проблему переобучения на редких картах без использования тяжелых графовых алгоритмов.
* **Сверх-ансамбль (Super-Ensemble)**: Математическое смешивание вероятностей оптимизированного по весам `CatBoostClassifier` (60% веса) и регуляризованного `LogisticRegression` (40% веса).
* **Бизнес-ориентированное управление порогом**: Модель оптимизирована под жесткое ограничение лояльности клиентов `Precision >= 72%`, что позволило выжать максимальный охват мошенников (`Recall = 98.90%`).

## Инструкция по запуску и воспроизведению

Проект работает локально и не требует подключения к внешним базам данных.

1. Клонируйте репозиторий и разверните виртуальное окружение:
```bash
python -m venv venv
source venv/bin/activate  # Для Windows: venv\Scripts\activate
pip install -r requirements.txt
```
2. Убедитесь, что исходные файлы `final_p2p_log.csv` и `final_trans_log.csv` находятся в папке `data/raw/`.
3. Последовательно выполните Jupyter-ноутбуки из директории `notebooks/`:
   * **`1_data.ipynb`** — Обработает сырые `.csv` файлы, проведет инженерию признаков и сохранит готовые `train_cleaned.csv` и `test_cleaned.csv` в папку `data/processed/`.
   * **`2_model&metrics.ipynb`** — Обучит модели, проведет расчет Target Encoding, построит сверх-ансамбль, сгенерирует визуальные дашборды и сохранит сериализованные компоненты системы в папку `models/`.
