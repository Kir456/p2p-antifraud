# Выявление мошеннических P2P-переводов с использованием CatBoost

## О проекте

Проект посвящён разработке системы автоматического обнаружения мошеннических P2P-транзакций на основе методов машинного обучения. В условиях роста объёмов цифровых платежей финансовые организации сталкиваются с необходимостью выявлять подозрительные операции в режиме реального времени, минимизируя как финансовые потери, так и влияние антифрод-системы на добросовестных клиентов.

Основная сложность данной задачи заключается в сильном дисбалансе классов. В реальных банковских данных мошеннические операции составляют лишь небольшую долю общего потока транзакций. Из-за этого классические подходы к классификации и стандартные метрики качества зачастую оказываются малоинформативными.

Целью проекта являлось создание модели, способной обнаруживать большую часть мошеннических операций при сохранении приемлемого уровня ложных блокировок. В качестве ключевого бизнес-требования был установлен показатель:

**Recall ≥ 70%**

то есть система должна выявлять не менее 70% всех мошеннических транзакций.

Такое ограничение отражает реальные требования антифрод-подразделений банков, поскольку пропуск мошенника зачастую обходится значительно дороже, чем дополнительная проверка легальной операции.

---

# Постановка задачи

Каждая транзакция должна быть отнесена к одному из двух классов:

* **0 — легальная операция**
* **1 — мошенническая операция**

На вход модели поступают признаки, характеризующие поведение клиента и параметры перевода:

* сумма операции;
* временные характеристики;
* историческая активность пользователя;
* агрегированные показатели поведения клиента;
* производные статистические признаки.

На выходе модель формирует вероятность того, что операция является мошеннической.

Полученная вероятность далее преобразуется в бинарное решение с использованием специально подобранного порога классификации.

# Метрики качества модели

В рамках проекта использовалось несколько метрик, каждая из которых отражает отдельный аспект качества модели.

## ROC-AUC

ROC-AUC показывает способность модели отделять мошеннические операции от легальных независимо от выбранного порога классификации.

Метрика принимает значения от 0 до 1:

* 0.5 — случайное угадывание;
* 1.0 — идеальное разделение классов.

Высокий ROC-AUC означает, что мошеннические операции в среднем получают более высокий риск-скор, чем легальные транзакции.

Однако в задачах антифрода ROC-AUC имеет ограниченную ценность, поскольку сильный дисбаланс классов может создавать чрезмерно оптимистичную оценку качества.

---

## Precision (Точность)

Precision показывает долю реально мошеннических операций среди всех операций, которые модель пометила как мошеннические.

Формула:

Precision = TP / (TP + FP)

где:

* TP — правильно найденный фрод;
* FP — ошибочно заблокированные легальные операции.

С точки зрения бизнеса Precision отвечает на вопрос:

**«Сколько действительно мошенников находится среди всех заблокированных транзакций?»**

Чем выше Precision, тем меньше ресурсов потребуется на ручную проверку операций.

---

## Recall (Полнота)

Recall показывает, какую долю всех мошеннических операций смогла обнаружить модель.

Формула:

Recall = TP / (TP + FN)

где:

* TP — найденный фрод;
* FN — пропущенный фрод.

С точки зрения антифрод-системы Recall является одной из наиболее критичных метрик.

Высокий Recall означает, что система успешно предотвращает финансовые потери, связанные с мошенническими переводами.

Именно поэтому в проекте использовалось бизнес-ограничение:

**Recall ≥ 70%**

что гарантирует обнаружение не менее 7 мошенников из 10.

---

## Precision-Recall AUC (PR-AUC)

Для задач с редким положительным классом наиболее информативной является метрика PR-AUC.

Она отражает качество компромисса между Precision и Recall на всех возможных значениях порога классификации.

В отличие от ROC-AUC, PR-AUC чувствительна к дисбалансу классов и позволяет объективно оценивать качество модели именно с точки зрения поиска мошенников.

По этой причине PR-AUC была выбрана основной метрикой оценки модели.

Рост PR-AUC означает, что модель стала лучше выделять мошеннические операции из общего потока транзакций.

# Подбор оптимального порога

После обучения модель возвращает вероятность принадлежности транзакции к классу мошенничества.

Для принятия бизнес-решения необходимо определить порог отсечения.

Например:

* вероятность 0.30 → операция считается легальной;
* вероятность 0.80 → операция считается мошеннической.

Выбор порога оказывает прямое влияние на показатели Precision и Recall.

Низкий порог:

* увеличивает Recall;
* увеличивает количество ложных срабатываний.

Высокий порог:

* уменьшает количество ложных срабатываний;
* увеличивает риск пропуска мошенников.

В рамках проекта был реализован алгоритм поиска оптимального порога по Precision-Recall Curve.

Из всех порогов выбирался тот, который обеспечивал:

* Recall ≥ 70%;
* максимальное значение Precision.

Такой подход позволяет напрямую учитывать бизнес-требования при эксплуатации модели.

# Анализ матрицы ошибок

Для оценки бизнес-эффекта использовалась матрица ошибок.

Она позволяет определить:

### True Positive (TP)

Мошенническая операция успешно обнаружена системой.

Это наиболее ценный для бизнеса результат.

### False Negative (FN)

Мошенническая операция была пропущена.

Именно такие случаи приводят к прямым финансовым потерям.

### False Positive (FP)

Легальная операция ошибочно признана мошеннической.

Такие операции создают дополнительную нагрузку на службу мониторинга и ухудшают клиентский опыт.

### True Negative (TN)

Легальная операция корректно пропущена системой.

Основная цель антифрод-модели заключается в максимизации TP и минимизации FN при контролируемом количестве FP.
